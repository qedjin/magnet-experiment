# 🧲 자석에 붙는 물체 찾기 - 3D 가상 실험

Three.js로 만든 브라우저 3D 가상 실험 콘텐츠입니다.

## 📁 프로젝트 구조

```
/
├── index.html     ← 메인 HTML
├── style.css      ← UI 스타일
├── app.js         ← Three.js 3D 로직 & 실험 플로우
└── models/        ← 여기에 glb 파일들을 넣어주세요!
    ├── bead.glb
    ├── bar_magnet.glb
    ├── basket.glb
    ├── aluminum_foil_dish.glb
    ├── pencil.glb
    ├── eraser.glb
    ├── desk.glb
    ├── iron_tongs.glb
    ├── iron_clip.glb
    └── plastic_ruler.glb
```

## ▶️ 실행 방법

**ES Module 방식이라 로컬 파일을 바로 열면 안 되고, 간단한 로컬 서버가 필요해요.**

### 방법 1: Python 사용 (권장)
```bash
cd 프로젝트폴더
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 열기

### 방법 2: VS Code 사용
`Live Server` 확장 프로그램 설치 → index.html에서 우클릭 → "Open with Live Server"

### 방법 3: Node.js 사용
```bash
npx serve .
```

## 🎮 사용 흐름

1. **예상하기**: 캐릭터가 등장해서 예상하라고 안내합니다. 각 물체가 자석에 붙을지(O) 안 붙을지(X)를 표에 체크합니다.
2. **실험하기**: 막대자석을 마우스로 드래그해서 물체에 가까이 가져갑니다.
   - 철 클립, 철 집게 → 자석에 붙음! 캐릭터가 "바구니에 옮겨요" 안내
   - 나머지 물체 → 반응 없음
3. **바구니로 옮기기**: 붙은 물체를 자석과 함께 바구니로 드래그하면 바구니에 담깁니다.
4. **비교하기**: 예상과 실제 결과를 비교합니다.
5. **정리 / 다시 하기**:
   - 정리하기 → 결론 문구 안내
   - 다시 하기 → 처음 상태로 초기화

## 🎛️ 조작 방법

- **마우스 드래그**: 막대자석 이동 (실험 단계일 때)
- **마우스 우클릭 드래그**: 카메라 시점 회전
- **마우스 휠**: 확대/축소
- **오른쪽 아래 🔄 초기화 버튼**: 언제든 초기화 가능

## 🔧 초보자를 위한 수정 팁

### 물체 위치 바꾸기
`app.js`의 `ITEMS` 배열에서 `pos: [x, z]` 값을 바꾸면 책상 위 위치가 변경됩니다.

### 물체 크기 조절
각 물체의 `scale` 값을 1.0 → 1.5 등으로 바꾸면 커집니다.

### 책상 방향 조정
만약 책상이 세로로 서 있다면 `app.js`에서 `desk.rotation.y = Math.PI / 2;` 주석을 해제하세요.

### 자석 위치 조절
`buildScene()` 함수 안에서 `magnet.position.set(-3.2, deskTopY + 1.4, 0);` 값을 조절하세요.

### 색상 바꾸기
`style.css`에서 `#42a5f5` 같은 색상 코드를 바꾸면 버튼과 배경 색이 바뀝니다.

## ⚠️ 문제 해결

- **모델이 안 보여요**: 브라우저 개발자 도구(F12) → Console 탭에서 에러를 확인하세요. 대부분 glb 파일 경로 문제입니다.
- **책상이 세로로 서 있어요**: `app.js`의 `desk.rotation.y` 주석을 해제하세요.
- **물체가 책상 밑이나 위에 떠 있어요**: `fitToSize`의 크기 값을 조절하거나, glb 모델 자체의 원점을 확인하세요.
- **나레이션이 안 나와요**: 브라우저가 음성 합성을 지원하는지 확인하세요 (Chrome, Edge 권장).
